API & Servidor MCP

Acesse dados oficiais de balneabilidade das praias paraibanas de forma estruturada para aplicações, automações e agentes inteligentes de IA.

Servidor MCP (Model Context Protocol)

Para agentes de IA (Claude Desktop, Cursor, Antigravity, ChatGPT)
Streamable HTTP

Endpoint compatível com a especificação oficial MCP via POST. Não exige autenticação. 

URL do Servidor: https://qualidade-nine.vercel.app/mcp

Ferramentas Registradas

consultar_praia(praia, municipio?)
Verifica se uma praia específica possui trecho impróprio no boletim vigente, detalhando os pontos exatos de coleta e orientações práticas de banho.
listar_improprias(municipio?)
Lista todos os trechos classificados como impróprios para banho no litoral da Paraíba (com filtro opcional por município).
boletim_atual()
Retorna o resumo do boletim ativo da SUDEMA: datas de coleta, validade, total de trechos impróprios, pontos monitorados e fontes.
listar_praias_monitoradas(municipio?)
Catálogo completo dos municípios e praias acompanhadas pelo órgão ambiental na Paraíba.

Como Configurar no Claude Desktop / Cursor

{
  "mcpServers": {

Regras de Domínio e Balneabilidade

1. Regra dos 100 Metros da SUDEMA: A classificação "imprópria" aplica-se a uma faixa de 100 metros à direita e 100 metros à esquerda do ponto específico de coleta. Fora dessa faixa delimitada, o restante da praia é considerado liberado.

2. Critério Própria vs. Imprópria: A SUDEMA monitora aproximadamente 62 pontos em 8 municípios litorâneos (João Pessoa, Cabedelo, Lucena, Pitimbu, Conde, Mataraca, Baía da Traição e Rio Tinto). As praias que não constam na lista de trechos impróprios estão consideradas próprias pelo órgão ambiental.

3. Ciclo Semanal: Novos boletins são divulgados semanalmente, tradicionalmente nas sextas-feiras, com validade até a emissão do boletim seguinte.
